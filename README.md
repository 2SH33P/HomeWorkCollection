# 错题收集工具（HomeWorkCollection）

本地/自托管的错题收集 WebUI：**拍整页试卷 → 框选题目 → AI 识别文字与公式 → 错题管理 → Typst 排版生成试卷 PDF**。手机、电脑浏览器均可使用，无需 Node / 数据库 / Docker，单 Python 进程即可运行。

## 功能特性

### 拍页与框选
- **整页上传**：手机拍照直接上传整页试卷（jpg/png/webp），自动生成缩略图，首页可勾选批量删除
- **框选题目**：拖拽框选，四角/四边可微调（触摸与鼠标分别设容差，圆形大手柄，拖动防抖），支持**跨页续块**合并，多页框选统一列表、统一科目
- **三种模式**：框题 / 缩放 / 编辑；缩放支持按钮、滚轮、双指、适应页面；撤销重做 60 步（`Ctrl+Z` / `Ctrl+Shift+Z`）
- **裁图**：对选中框框选题内图形，手动补裁未裁好的题

### AI 识别
- 视觉大模型一次性识别 **题干 + 选项**（分开填充）、数学/化学公式转 **LaTeX**、自动忽略手写笔迹、题号、答案、页眉页脚与署名
- **识图 API 可配置**（设置页填写，兼容任意 OpenAI 接口的服务）
- **化学式 `\ce{}`** 预处理（花括号配对扫描 + 箭头映射），公式统一经 **mitex** 转 Typst
- **题内图形**：AI 输出 `[图N]` 标记，坐标为内部数据，PDF 自动插入并可与文字并排
- 手填内容不会被 AI 覆盖（「AI识别」按钮可强制重识别）
- 识别失败可在设置页查看运行日志（最近 300 条），并可开启额外校对

### 错题库
- 科目 → 大题 → 日期 三级浏览，默认折叠；搜索支持编号/题干/选项/解析
- 日期 + 星级筛选，列表/相册两种视图（记忆选择），批量删除
- 全屏编辑窗（左图右文），字段实时局部同步，附件上传/插入引用
- **手动添加题目**（可不上传图片，纯文字题全流程兼容）
- **图片浏览**：裁剪图 ⟷ 原图切换，`Ctrl+滚轮` 缩放
- **大题归类**：输入框 + ▾ 按钮，一键列出该科目**全部预设大题**（来自「组卷打印 → 大题模板」），也可自由输入

### 组卷打印
- 勾选题目按顺序自动编号，按「大题归属」分组（黑体大题标题，空值/未命名不显示标题行）
- **16 开高考卷风格 PDF**（Typst 排版，文字可复制）
  - 页边距上下 2cm、左右 2.2cm；正文宋体五号、1.5 倍行距；题目之间 0.45cm 间距
  - 英文 Times New Roman / 中文宋体 / 大题标题黑体 / `*斜体*` → 楷体 / `**粗体**` → 黑体
  - 选项按显示宽度自适应一行四列 / 两列 / 一列
  - `::: center ... :::` 段落居中；`[图N]`、`[图N|宽|对齐]` 插图，整行多图自动并排
  - 页脚「第 X 页　共 Y 页」，页眉/卷头（标题、科目行、注意事项）可自定义
- **答案解析附录**（不附加 / 仅答案 / 仅解析 / 两者）+ **题目编号对照页**
- **编号系统**：科目独立前缀（`MA`/`PH`/`CH`/`BI`/`EN`/`CN`/`ZZ`/`LS`/`DL`/`OT`，界面可改），位数自适应（`MA0001` → `MA10000` → …）

### 数据安全
- 每次写库前自动备份到 `backups/`（保留 30 份）
- 删除页面/错题时文件移入 `.trash/`（可恢复），不做物理删除
- **导出/导入**：一键导出 ZIP（题库 + 图片 + 模板 + 前缀配置），导入时校验包、图片重名自动改名、题目全部重新编号（绝不覆盖现有数据）

## 语文卷等文科卷的排版

识别与排版支持以下正文标记（AI 识别会自动输出大部分，也可手动书写）：

| 标记 | 作用 |
|---|---|
| `**文字**` | 黑体（原题的加粗/黑体）|
| `*文字*` | 楷体（原题的楷体/斜体）|
| `===文字==` | 宋体加粗（描边合成）|
| `++文字++` | 黑体加粗 |
| `***文字***` | 楷体加粗 |
| `^文字^` | 上标角标，如 `乡校^①^`、`清机^[注]^` |
| `**材料一：**` | 材料标签（单独一行，齐左）|
| `::: poem` … `:::` | 整首诗歌/词曲：整段居中 + 加大行距，每句一行 |
| `::: quote` … `:::` | 注释、出处、摘编说明、引文：左右缩进 |
| `::: center` … `:::` | 逐行居中 |
| `$...$` | 数学/化学公式（LaTeX，经 mitex 渲染）|

**卷头设置**（组卷页 → 卷头与页眉设置）：标题、科目名、副标题（适用省份/考试时间）、注意事项
（首行黑体标题、其余逐条成行）、页眉；并可设置**正文字号**（五号/小四 12pt/四号）、
**行距**（0.95/1.25/1.5/1.75 倍）、**段落首行缩进**（不缩进/2 字符）。

**语文卷推荐**：小四 12pt + 1.5 倍行距 + 首行缩进 2 字符。

**分节块**：手动添加题目时勾选「作为分节块」，该条不参与编号，只输出一行黑体标题，
用于「一、阅读（72 分）」「（一）现代文阅读 I（本题共 5 小题，19 分）」这类大题标题，
或整段阅读材料（此时在该条里写 `**材料一：**` 与材料正文）。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python · FastAPI · Uvicorn |
| 图像处理 | OpenCV · NumPy · Pillow（裁剪 / 坐标换算 / 收边 / 去笔迹） |
| PDF 排版 | Typst（PyPI 包）+ **mitex**（LaTeX 公式）+ 本地字体 |
| AI 识别 | 任意 OpenAI 兼容的视觉模型（默认预设 DeepSeek `deepseek-flash`） |
| 前端 | 原生 HTML/CSS/JavaScript · Canvas 2D · Pointer Events |

**内置字体**（已随仓库打包，无需上传）：`fonts/` 中的宋体 SimSun、黑体 SimHei、楷体 KaiTi 与 Times New Roman。

## 快速开始

### Windows（推荐）

1. 安装 Python 3.10+（勾选 *Add Python to PATH*）
2. 双击 `start.bat`，首次运行自动创建虚拟环境并安装依赖（约 2 分钟）
3. 浏览器自动打开 `http://localhost:8091`
4. 手机与电脑同一 WiFi 时，手机访问 `http://电脑IP:8091` 即可上传照片

打包为单文件 exe：运行 `build.bat`（PyInstaller）。Windows 详细说明见 `README-Windows.txt`。

### 手动运行（任意平台）

```bash
pip install fastapi "uvicorn[standard]" python-multipart pillow opencv-python-headless numpy typst
python tools/crop-tool/app.py
# 访问 http://localhost:8091
```

### 配置 AI（可选但强烈建议）

启动后打开 **「设置」** 页填写，或在项目目录创建 `.ai_config.json`：

```json
{
  "base_url": "https://api.deepseek.com/v1",
  "model": "deepseek-flash",
  "key": "你的 API Key"
}
```

| 项 | 说明 |
|---|---|
| 预设 | DeepSeek 多模态 `deepseek-flash`（自动关闭思考提速）|
| 自定义 | 任何 OpenAI 兼容接口均可：填 `base_url` + `model` + `key`即可 |
| 识别清晰度 | 1200 / 1600 / 2200 / 2800 像素（越大越准、越慢）|
| 额外校对 | 开启后对识别结果做二次校对 |
| 测试连接 | 设置页可一键验证配置是否可用 |

> **重要**：识别图片必须使用**支持图片输入**的模型；纯文本模型（如 `deepseek-chat`）会静默忽略图片，输出残缺内容。
>
> **维护提示**：AI 接口偶有不稳定，如遇识别失败或超时，稍后重试或直接手动框选/裁图，不影响其他功能。

## 使用流程

```
1. ① 整页框选：上传整页照片 → 拖拽框选每道题 →（可选）裁图 →  保存（弹出确认框显示科目与题数）
2. 保存后自动 AI 识别：题干 + 选项分开、公式 LaTeX、图形自动裁剪；没裁好的题红框标记
3. ② 错题库：科目 → 大题 → 日期 三级浏览；预览/编辑识别内容，可手动裁图、补答案与解析
4. ③ 组卷：勾选题目（按顺序编号）→ 调整大题归属 → 自定义卷头 → 生成 PDF（可附答案/解析与编号对照）
```

## 目录结构

```
├── tools/crop-tool/
│   ├── app.py                # FastAPI 后端（全部接口 + Typst 排版）
│   └── static/index.html     # 单页前端（原生 JS）
├── typst-packages/           # 本地 Typst 包（mitex: LaTeX → Typst）
├── fonts/                    # 内置排版字体（宋体/黑体/楷体/Times）
├── start.bat / start.sh      # 一键启动
├── build.bat                 # PyInstaller 打包
└── README-Windows.txt        # Windows 详细说明
```

运行时数据（目录名为英文，界面显示中文）：

```
pages/                   整页上传照片（P1/P2… 按上传时间编号）
items/{math,physics,chemistry,biology,english,chinese,politics,history,geography,other}/
                         裁剪出的错题图
library.json             错题库数据
chapter_templates.json   大题模板（按科目）
code_prefix.json         编号前缀
backups/                 写库前自动备份（保留 30 份）
.trash/                  删除的图片（可恢复）
.tmp/                    临时文件
```

备份：直接复制上述目录即可；或使用设置页的「导出数据」生成 ZIP。

## 隐私说明

- AI 识别会将题目图片发送至**你自己配置的** API 服务商；如题含敏感内容请谨慎
- API Key 仅保存在本地 `.ai_config.json`（已加入 `.gitignore`，不会提交），界面只显示掩码
- 除 AI 识别外，所有数据仅存于本机，不上传任何其他服务
