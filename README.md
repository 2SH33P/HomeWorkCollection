# 错题收集工具（HomeWorkCollection）

本地/自托管的错题收集 WebUI：**拍整页试卷 → 框选题目 → AI 识别文字与公式 → 错题管理 → Typst 排版生成试卷 PDF**。手机、电脑浏览器均可使用，无需 Node / 数据库 / Docker，单 Python 进程即可运行。

> 📖 **详细使用教程**（安装 / AI 配置 / 框选 / 图块 / 组卷 / 自动组卷 / 排版微调 / 数据仓库 / FAQ）：
> <https://2sh33p.github.io/HomeWorkCollection/>　源文件在 [`docs/`](docs/)，用 MkDocs 构建。

## 功能特性

### 拍页与框选
- **整页上传**：手机拍照直接上传整页试卷（jpg/png/webp），自动生成缩略图，首页可勾选批量删除
- **框选题目**：拖拽框选，四角/四边可微调（触摸与鼠标分别设容差，圆形大手柄，拖动防抖），支持**跨页续块**合并，多页框选统一列表、统一科目
- **三种模式**：框题 / 缩放 / 编辑；缩放支持按钮、滚轮、双指、适应页面；撤销重做 60 步（`Ctrl+Z` / `Ctrl+Shift+Z`）
- **裁图**：对选中框框选题内图形，手动补裁未裁好的题

### AI 识别
- 视觉大模型一次性识别 **题干 + 选项**（分开填充）、数学/化学公式转 **LaTeX**、自动忽略手写笔迹、题号、答案、页眉页脚与署名
- **识图 API 可配置**（设置页填写，兼容任意 OpenAI 接口的服务）
- **化学式 `\ce{}`** 预处理（花括号配对扫描 + 箭头映射），公式统一经 **mitex** 转 Typst
- **题内图形**：AI 识别时按图形在题目里的位置自动插入 `[图1]`、`[图2]`… 标记（从上到下、从左到右编号）；用户再把裁好 / 上传的图**绑定到对应编号**，正文渲染时图就出现在原位
- **图注**：`[图注:说明文字]` 写在与图片同一行的下一行，即排在图片正下方（见「排版微调」）
- 手填内容不会被 AI 覆盖（「AI识别」按钮可强制重识别）
- 识别失败可在设置页查看运行日志（最近 300 条），并可开启额外校对

### 错题库
- 科目 → 大题 → 日期 三级浏览，默认折叠；搜索支持编号/题干/选项/解析
- 日期 + 星级筛选，列表/相册两种视图（记忆选择），批量删除
- 全屏编辑窗（左图右文），字段实时局部同步，附件上传/插入引用
- **手动添加题目**（可不上传图片，纯文字题全流程兼容）
- **图片浏览**：裁剪图 ⟷ 原图切换，`Ctrl+滚轮` 缩放
- **大题归类**：输入框 + ▾ 按钮，一键列出该科目**全部预设大题**（来自「组卷打印 → 大题模板」），也可自由输入
- **一键全局改名**：标签（大题归类）、关键字、科目及其编号前缀都可在设置页一键改名，
  一次改完**全部覆盖**（题目 / 大题模板 / 编号同步更新，写库前自动备份 `library.json`）

### 组卷打印
- 勾选题目按顺序自动编号，按「大题归属」分组（黑体大题标题，空值/未命名不显示标题行）
- **16 开高考卷风格 PDF**（Typst 排版，文字可复制）
  - 页边距上下 2cm、左右 2.2cm；正文宋体五号、1.5 倍行距；题目之间 0.45cm 间距
  - 英文 Times New Roman / 中文宋体 / 大题标题黑体 / `*斜体*` → 楷体 / `**粗体**` → 黑体
  - 选项按显示宽度自适应一行四列 / 两列 / 一列
  - `::: center ... :::` 段落居中；`[图N]`、`[图N|宽|对齐]` 插图，整行多图自动并排
  - 页脚「第 X 页　共 Y 页」，页眉/卷头（标题、科目行、注意事项）可自定义
- **答案解析附录**（不附加 / 仅答案 / 仅解析 / 两者）+ **题目编号对照页**
- **编号系统**：科目独立前缀（`MA`/`PH`/`CH`/`BI`/`EN`/`CN`/`ZZ`/`LS`/`DL`/`OT`，界面可改），位数自适应（`MA0001` → `MA10000` → …）

### 数据安全
- 每次写库前自动备份到 `backups/`（保留 30 份）
- 删除页面/错题时文件移入 `.trash/`（可恢复），不做物理删除
- **导出/导入**：一键导出 ZIP（题库 + 图片 + 模板 + 前缀配置），导入时校验包、图片重名自动改名、题目全部重新编号（绝不覆盖现有数据）

## 语文卷等文科卷的排版

识别与排版支持以下正文标记（AI 识别会自动输出大部分，也可手动书写）：

| 标记 | 作用 |
|---|---|
| `**文字**` | 黑体（原题的加粗/黑体）|
| `*文字*` | 楷体（原题的楷体/斜体）|
| `===文字==` | 宋体加粗（描边合成）|
| `++文字++` | 黑体加粗 |
| `***文字***` | 楷体加粗 |
| `^文字^` | 上标角标，如 `乡校^①^`、`清机^[注]^` |
| `**材料一：**` | 材料标签（单独一行，齐左）|
| `::: poem` … `:::` | 整首诗歌/词曲：整段居中 + 加大行距，每句一行 |
| `::: quote` … `:::` | 注释、出处、摘编说明、引文：左右缩进 |
| `::: center` … `:::` | 逐行居中 |
| `$...$` | 数学/化学公式（LaTeX，经 mitex 渲染）|
| `[图N]` | 插图：默认高度为版心的 24%（约 5.3cm），宽度按原图比例自动计算，**右对齐** |
| `[图N\|60%]` | 指定宽度为版心的 60%（也接受 cm，如 `[图1\|8cm]`）|
| `[图N\|32%h]` | 指定高度为版心的 32%（尾字母 `h` 表示按高度）|
| `[图N\|60%\|left]` | 指定宽度 + 对齐（`left` / `center` / `right`，**默认右对齐**）|
| `[图注:说明文字]` | 图下注释：写在与图片同一行的**下一行**，居中排在图片正下方（字号 88%）|
| `\| 表头 \| 表头 \|` + `\| --- \| :--: \|` | 表格（Markdown 管道表 → 三线表，第二行分隔行决定各列对齐，`--:` 右对齐、`:--:` 居中、`---` 居中）|

**卷头设置**（组卷页 → 卷头与页眉设置）：标题、科目名、副标题（适用省份/考试时间）、注意事项
（首行黑体标题、其余逐条成行）、页眉；并可设置**正文字号**（五号/小四 12pt/四号）、
**行距**（0.95/1.25/1.5/1.75 倍）、**段落首行缩进**（不缩进/2 字符）。

**语文卷推荐**：小四 12pt + 1.5 倍行距 + 首行缩进 2 字符。

**英语试卷**：题目文字保持英文原样；完形填空/语法填空的小题号（41. 61.）会保留；
填空的空格 `______` 与括号提示词 `(be)` 原样保留；选项支持 A～G（七选五）。

**分节块**：手动添加题目时勾选「作为分节块」，该条不参与编号，只输出一行黑体标题，
用于「一、阅读（72 分）」「（一）现代文阅读 I（本题共 5 小题，19 分）」这类大题标题，
或整段阅读材料（此时在该条里写 `**材料一：**` 与材料正文）。

## 排版微调（字体 / 图片大小与对齐）

以上设置都不需要改代码，改完重新生成 PDF 即可。

### 换字体

内置字体已随仓库打包，位于 `fonts/`：

| 文件 | 用途 |
|---|---|
| `simsun.ttc` | 正文中文（宋体）|
| `simhei.ttf` | 大题标题 / `**粗体**`（黑体）|
| `simkai.ttf` | `*斜体*`（楷体）|
| `times*.ttf` | 西文与数字（Times New Roman 正/粗/斜）|

换字体只需**把 `fonts/` 里的文件替换成同名文件**（如换成思源宋体后命名为 `simsun.ttc`），重启服务即可，
排版代码无需改动。若新字体文件名不同，搜索 `app.py` 中的 `F_SONG` / `F_HEI` / `F_KAI` / `F_LATIN` 四个变量，
把其中的字体名改成新字体名即可（Typst 用的是字体的内部名称，不一定等于文件名）。

### 调图片大小与对齐

正文里直接写标记（在错题库的「识别内容 / 答案 / 解析」里）：

| 写法 | 效果 |
|---|---|
| `[图1]` | 默认大小：高度 = 版心 24%（约 5.3cm），宽度按原图比例自动算，**右对齐** |
| `[图1\|12%h]` | 高度 = 版心 12%（越小越矮，适合小题图）|
| `[图1\|80%]` | 宽度 = 版心 80% |
| `[图1\|50%\|left]` | 宽度 50%、左对齐（可 `left` / `center` / `right`）|
| `[图1\|8cm]` | 固定宽度 8cm |
| `[图1\|6cmh]` | 固定高度 6cm（尾字母 `h`）|

- 整行只写图 = 单图（或一行多图并排）；图与文字同行 = 行内插图。
- **默认高度**可在组卷页「卷头与页眉设置 → 图片默认高度」里整体调（16% / 20% / 24% / 28% / 32%）。
- 不论哪种写法都**不会超出版心**：过高的图自动改按高度定尺寸，过宽的图自动改为 `width: 100%`。
- **图注**：在图片行的下一行写 `[图注:说明文字]`，会以 88% 字号居中排在图片正下方。
- 未裁磨好的图会渲染成红色「图N未裁好」提示，不会影响其他内容。

### 调对齐 / 行距 / 字号

组卷页「卷头与页眉设置」里可改：正文字号（五号 / 小四 12pt / 四号）、行距（0.95～1.75 倍）、
段落首行缩进（不缩进 / 2 字符）、图片默认高度；段落级对齐用 `::: center` … `:::`、
诗歌用 `::: poem`、引文/材料用 `::: quote`。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python · FastAPI · Uvicorn |
| 图像处理 | OpenCV · NumPy · Pillow（裁剪 / 坐标换算 / 收边 / 去笔迹） |

## 快速开始

### Windows（推荐）

1. 安装 Python 3.10+（勾选 *Add Python to PATH*）
2. 双击 `start.bat`，首次运行自动创建虚拟环境并安装依赖（约 2 分钟）
3. 浏览器自动打开 `http://localhost:8091`
4. 手机与电脑同一 WiFi 时，手机访问 `http://电脑IP:8091` 即可上传照片

打包为单文件 exe：运行 `build.bat`（PyInstaller），或用 GitHub Actions 自动编译（见「编译产物」）。
Windows 详细说明见 `README-Windows.txt`。

### 手动运行（任意平台）

```bash
pip install fastapi "uvicorn[standard]" python-multipart pillow opencv-python-headless numpy typst
python tools/crop-tool/app.py
# 访问 http://localhost:8091
```

### 改完代码先跑自检

```bash
bash tools/selfcheck/run.sh      # 前端纯逻辑 + 后端逻辑，共 50+ 项，不碰用户数据
```

### 配置 AI（可选但强烈建议）

启动后打开 **「设置」** 页填写，或在项目目录创建 `.ai_config.json`：

```json
{
  "base_url": "https://api.deepseek.com/v1",
  "model": "deepseek-flash",
  "key": "你的 API Key"
}
```

| 项 | 说明 |
|---|---|
| 预设 | DeepSeek 多模态 `deepseek-flash`（自动关闭思考提速）|
| 自定义 | 任何 OpenAI 兼容接口均可：填 `base_url` + `model` + `key`即可 |
| 识别清晰度 | 1200 / 1600 / 2200 / 2800 像素（越大越准、越慢）|
| 额外校对 | 开启后对识别结果做二次校对 |
| 测试连接 | 设置页可一键验证配置是否可用 |

> **重要**：识别图片必须使用**支持图片输入**的模型；纯文本模型（如 `deepseek-chat`）会静默忽略图片，输出残缺内容。
>
> **维护提示**：AI 接口偶有不稳定，如遇识别失败或超时，稍后重试或直接手动框选/裁图，不影响其他功能。

## 使用流程

```
1. ① 整页框选：上传整页照片 → 拖拽框选每道题 →（可选）裁图 →  保存（弹出确认框显示科目与题数）
2. 保存后自动 AI 识别：题干 + 选项分开、公式 LaTeX（**图形不参与识别，需人工裁图**）
3. ② 错题库：科目 → 大题 → 日期 三级浏览；预览/编辑识别内容，可手动裁图、补答案与解析
4. ③ 组卷：勾选题目（按顺序编号）→ 调整大题归属 → 自定义卷头 → 生成 PDF（可附答案/解析与编号对照）
```

## 自动组卷

按「大题 + 星级」约束从题库抽题，一次生成多份**互不重复**的卷子（组卷页 → 自动组卷）。

| 能力 | 说明 |
|---|---|
| 题量 | 每个大题单独设置要几道（如选择题 8 道、解答题 6 道）|
| 星级约束 | 每星级可设**最少/最多**（留空=不限），如「2 星 2～3 道、3 星至少 2 道、4 星最多 2 道」|
| 卷内排序 | 大题内一律**星级从低到高**；大题顺序按你填写顺序 |
| 跨份不重复 | 多份卷子之间的题目**完全不重复**（指定题目除外，它每份都有）|
| 指定题目 | 可输入编号 / 把错题库里勾选的题加入「指定题目」，指定题**每份卷子必含**（排在该大题最前），其余题照常随机出 |
| 预检可行性 | 生成前告出「最多能出几份」以及卡在哪个大题/星级 |
| 关键字去重 | 可选：同一份卷内不出现相同关键字（避免重复考同一知识点）|
| 避开上次 | 可选：跳过上次自动组卷用过的题（记录在 `auto_last.json`）|
| 输出 | 每份可「载入到组卷」再微调，或单独「导出 PDF」，也可「全部导出 ZIP」|

算法：先按全局配额算出**每份卷每个星级各拿几道**（保证星级上下限与题量都能满足），
再对每个星级洗牌发牌；配额按剩余份数均分，避免某一份把稀缺星级的题用光。
指定题目每份都排在本大题最前，并从随机池中排除（不占随机配额、不判重复）。

### 数据存在哪？怎么备份 / 导出？

- **编译成 exe 后**：数据就存在 **exe 所在目录**（不是临时目录）。图片在 `items/`，题库是 `library.json`；
  把 exe 拷到另一个文件夹就会用那个文件夹的数据。升级 exe 时替换可执行文件即可，数据不动。
- **导出**：设置页「导出全部数据（ZIP）」将当前仓库的题库 + 图片 + 配置打包下载；
  导入时全部重新编号，不覆盖现有数据。最简单的备份就是直接复制整个数据目录。

## 数据仓库（切换 / 合并，类似 Obsidian 仓库）

设置页「数据仓库」可把数据在多个互相独立的仓库（文件夹）之间切换，适合「不同学科/不同学生/不同学期」各用一套题库：

| 操作 | 说明 |
|---|---|
| 切换 | 在下拉框选仓库 → 切换；页面刷新后加载该仓库的题库与图片 |
| 新建并切换 | 在 `vaults/<名字>/` 建一个空仓库（原数据仍留在原仓库）|
| 当前仓库改名 | 仓库目录一并改名 |
| 合并（保留源仓库）| 把另一个仓库的题**复制**进当前仓库：图片一并复制、题目重新编号，现有题目不被覆盖，**源仓库保留不动** |

默认仓库就是程序目录本身（兼容旧数据）；`vaults/` 下已存在的子目录会被自动识别为仓库。
切仓库只影响当前会话的服务端，无任何数据被删除或覆盖。

## 编译产物（GitHub Actions）

仓库自带 `.github/workflows/build.yml`：

- **推送到 `main`** / Actions 页手动触发 → 只编译并上传 **Artifacts**（不发布任何东西）；
- **打 tag（`v1.0` 这类）** → 编译后**自动创建 GitHub Release**，把 Windows / macOS 压缩包作为附件传上去
  （下载地址：<https://github.com/2SH33P/HomeWorkCollection/releases>）。

| 产物 | 内容 |
|---|---|
| `HomeWorkCollection-<版本>-windows.zip` | 单文件 exe + 内置字体 + Typst 包（解压即用）|
| `HomeWorkCollection-<版本>-macos-<arch>.zip` | macOS 可执行文件 + 内置字体 + Typst 包 |

| 产物 | 内容 |
|---|---|
| `HomeWorkCollection-windows` | `HomeWorkCollection.exe` + `fonts/` + `typst-packages/` |
| `HomeWorkCollection-macos-<arch>` | `HomeWorkCollection` 可执行文件 + `fonts/` + `typst-packages/`（zip）|

在 workflow 运行页面底部 **Artifacts** 区域下载。解压后把可执行文件和 `fonts/`、`typst-packages/`
放在同一目录，双击 / `./HomeWorkCollection` 运行，数据就存在该目录。

**升级 exe**：数据（`library.json`、`items/`…）就在 exe 同目录，升级**只需用新 exe 覆盖旧 exe**，
切勿删除或更换数据目录；详见教程《安装与启动 → 升级》（<https://2sh33p.github.io/HomeWorkCollection/install/#升级>）。

备份：直接复制上述数据目录即可；或使用设置页的「导出数据」生成 ZIP。

## URL 直达

| 地址 | 页面 |
|---|---|
| `/editor` | 整页框选 |
| `/library` | 错题库（科目列表）|
| `/library/数学` | 指定科目 |
| `/item/MA0003` | 直接打开该题的全屏编辑窗口 |
| `/paper` | 组卷打印 |
| `/settings` | 设置（AI 配置 + 运行日志）|

## 隐私说明

- AI 识别会将题目图片发送至**你自己配置的** API 服务商；如题含敏感内容请谨慎
- API Key 仅保存在本地 `.ai_config.json`（已加入 `.gitignore`，不会提交），界面只显示掩码
- 除 AI 识别外，所有数据仅存于本机，不上传任何其他服务
