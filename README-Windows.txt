============================================================
  错题收集工具 - Windows 使用说明
============================================================

【第一步】安装 Python（只需一次）
  1. 打开 https://www.python.org/downloads/
  2. 下载最新版，安装时【务必勾选】"Add Python to PATH"
  3. 装完重启一次命令行

【第二步】启动工具
  1. 双击本文件夹里的【启动.bat】
  2. 首次运行会显示"准备环境"，等约 2 分钟（装依赖）
  3. 浏览器自动打开 http://localhost:8091
  4. 黑色命令行窗口【不要关】，那是服务在运行

【第三步】上传错题照片
  方式 A（电脑上）：浏览器里点上传区，从电脑选照片
  方式 B（手机拍照）：
    1. 手机连【同一个 WiFi】
    2. 电脑上按 Win+R，输入 cmd 回车，输入 ipconfig 回车
       找到 "IPv4 地址"（类似 192.168.1.5）
    3. 手机浏览器访问 http://电脑的IPv4地址:8091
    4. 点上传区，直接拍照或从相册选

【第四步】框选题目
  1. 点页面缩略图打开
  2. 鼠标拖框框住题目，右侧填：题号/科目/章节/错因
  3. 点"保存到错题库"

【第五步】跨页题（一道题跨正反两页）
  方法A（推荐）："跨页拼接"里选那两张照片 -> 点"拼接"
              -> 拼成一张长图 -> 再框选，一次搞定
  方法B：两张照片各框一部分 -> 点框选列表里的"续块"连成一组
              -> 组卷时自动合并编号，显示 (续)

【第六步】去红笔/手写
  错题库里每张卡片左上角"清理"按钮
  - 去红笔：一键清除红叉红勾
  - 橡皮擦：涂抹要清除的草稿痕迹
  - 保存前原图自动备份为"xxx_原版.jpg"

【第七步】组卷打印
  错题库勾选题目 -> "组卷打印" -> 生成试卷（自动编号、续块合并）
  -> 浏览器打印，选"另存为 PDF"

【停止服务】关闭黑色命令行窗口即可

【可选】打包成免安装单文件 exe（给别人用）
  双击【打包.bat】，等 3-5 分钟，
  产物在 dist\错题收集工具.exe，拷到任何电脑双击即用
  （对方电脑无需装 Python）

【数据位置】
  所有数据（照片/错题/错题库.json）都保存在本文件夹内
  备份 = 直接复制整个文件夹
============================================================
