============================================================
  错题收集工具 - Windows 使用说明
============================================================

【第一步】安装 Python（只需一次）
  1. 打开 https://www.python.org/downloads/
  2. 下载最新版，安装时【务必勾选】"Add Python to PATH"
  3. 装完重启一次电脑

【第二步】启动工具
  1. 双击本文件夹里的【start.bat】
  2. 首次运行会自动创建运行环境并安装依赖（约 2-3 分钟），窗口会显示进度
  3. 浏览器自动打开 http://localhost:8091
  4. 黑色命令行窗口【不要关】，那是服务在运行

【第三步】配置 AI 识别（建议配置一次）
  1. 点页面顶部「设置」
  2. 填 API 地址、模型名、API Key（默认预设已填好 DeepSeek）
  3. 点「测试连接」确认可用
  4. 不配置也能用：手动框选 + 手动输入题目内容，只是没有自动识别

【第四步】上传错题照片
  方式 A（电脑上）：点上传区，从电脑选照片（可多选）
  方式 B（手机拍照）：
    1. 手机连【同一个 WiFi】
    2. 电脑上按 Win+R，输入 cmd 回车，输入 ipconfig 回车
       找到 "IPv4 地址"（类似 192.168.1.5）
    3. 手机浏览器访问 http://电脑的IPv4地址:8091
    4. 点上传区，直接拍照或从相册选

【第五步】框选题目
  1. 点页面缩略图打开照片
  2. 拖拽框住每道题（四角/四边可微调），右侧填写科目、大题归类等
  3. 一道题跨正反两页：两张照片各框一部分，然后点框选列表里的
     「续块」把它们连成一组，组卷时会自动合并编号并显示"(续)"
  4. 要裁出题内图形：选中框，点工具栏「裁图」，在图上拖框
  5. 点「完成」退出编辑（画布锁定，再点遮罩可重新进入）

【第六步】保存与 AI 识别
  1. 点「保存到错题库」，弹出确认框（显示科目与题数）
  2. 保存后自动 AI 识别：题干与选项分开、公式转 LaTeX、图形自动裁剪
  3. 没裁好的题会红框标记；识别结果可在错题库里随时修改

【第七步】错题库管理
  - 科目 -> 大题 -> 日期 三级浏览；可搜索编号/题干/选项/解析
  - 按日期、星级筛选；列表/相册两种视图（会记住选择）；支持批量删除
  - 点题目打开全屏编辑窗：左边原图、右边文字，可改题干/选项/答案/解析
  - 「手动添加题目」可纯文字录入，不需要图片
  - 「浏览图片」可切换裁剪图与原图

【第八步】组卷打印
  1. 在错题库勾选题目
  2. 切到「组卷打印」：可调整每道题的大题归属、卷头（标题/科目行/注意事项）、
     页眉，选择是否附答案解析（可在末尾附加）
  3. 点生成 PDF，得到 16 开高考卷风格 PDF（文字可复制、公式已排版）
  4. 编号自动生成：数学 MA0001、物理 PH0001、化学 CH0001 ... 位数自动增长

【数据安全】
  - 所有数据都在本文件夹：pages（整页照片）、items（错题图）、library.json（题库）
  - 每次写库前自动备份到 backups/（保留最近 30 份）
  - 删除照片/错题时文件移入 .trash/，不会真正删除，可手动取回
  - 「设置 -> 导出数据」可打包成 ZIP 备份；换电脑后用「导入数据」恢复

【停止服务】关闭黑色命令行窗口即可

【可选】打包成免安装单文件 exe（给别人用）
  1. 双击【build.bat】，等 3-5 分钟
  2. 产物在 dist\HomeWorkCollection.exe
  3. 使用时把 exe 与 fonts、typst-packages 两个文件夹放在同一目录，
     双击 exe 即可（数据会保存在该目录）

【常见问题】
  Q: 双击 start.bat 出现一堆乱码/提示"不是内部或外部命令"
  A: 说明文件被改成了错误的行尾格式，重新下载完整包覆盖即可
     （批处理必须用 CRLF 行尾，仓库已用 .gitattributes 固定）

  Q: 生成 PDF 时报错
  A: 多数是缺少 typst 依赖，删掉 .venv 文件夹后重新双击 start.bat

  Q: 手机打不开页面
  A: 确认手机与电脑在同一 WiFi；Windows 防火墙首次会弹窗，选"允许访问"
