# 错题收集工具 · 使用教程

> 拍整页试卷 → 框选题目 → AI 识别文字与公式 → 错题管理 → Typst 排版生成试卷 PDF。
> 手机、电脑浏览器都能用，单 Python 进程运行，无需 Node / 数据库 / Docker。

## 最短路径（5 分钟）

```text
1. 启动服务（Windows 双击 start.bat）→ 浏览器打开 http://localhost:8091
2. 设置 → 配置 AI（智谱 glm-4v-flash 免费）→ 保存 → 测试连接
3. 「① 整页框选」上传试卷照片 → 拖拽框选每道题 → 保存到错题库（自动 AI 识别）
4. 「② 错题库」核对识别内容、裁题内图形、补答案与解析
5. 「③ 组卷」勾选题目 → 填卷头 → 生成 PDF
```

## 你需要准备

| 项 | 说明 |
|---|---|
| 运行环境 | Python 3.10+（推荐 3.11/3.12）；或直接下载编译好的 Windows exe / macOS 可执行文件 |
| AI 接口 | 任意 **OpenAI 兼容**的视觉模型。免费可选智谱 `glm-4v-flash`（见 [配置 AI 识别](ai-setup.md)）|
| 浏览器 | Chrome / Edge / Safari / 手机浏览器均可（前端为原生 JS + Canvas，无需安装 App）|

## 三件「先知道」的事

!!! warning "服务没有登录鉴权"
    任何人只要能访问 `8091` 端口，就能查看/修改你的题库、AI 配置。**只在内网使用**，不要做公网端口映射或内网穿透；必须暴露时，请在前面加一层反向代理 + Basic Auth。

!!! note "数据存在哪"
    数据（图片、题库、配置）存在**程序目录**；编译成 exe 后就是 **exe 所在目录**。详见 [数据与仓库](data-vault.md)。

!!! note "隐私"
    AI 识别时，只有**裁剪后的单题图片**会发给你自己配置的 API 服务商，其余数据不出本机。题含敏感内容时请谨慎。
