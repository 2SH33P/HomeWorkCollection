# AI 识别与图片

## 识别规则（AI 会做什么）

视觉大模型一次性识别 **题干 + 选项**（分开填充），并遵守这些规则：

- 数学/化学公式转 **LaTeX**，统一用 `$...$` 包裹，经 mitex 渲染；
- **忽略**手写笔迹、批注、涂改、页眉页脚、页码、水印、署名、答案与解析；
- **删掉题号**（`1.` `①②`），但英语完形填空/语法填空的小题号（`41.` `61.`）保留；
- 选择题选项逐行输出（`A．B．C．D．`，全角句点）；
- **图形不描述、也不插图块标记**：AI 只负责文字。图块由你自己裁/传后再引用（点图片附件的「插入」或「裁图到 [图N]」，正文里就会出现 `[图N]`）。

手填的内容不会被覆盖；要强制重识别，点该题的 **「AI 识别」** 按钮。

## 图块：从「有标记」到「有图片」

图片（题内图形）要你自己裁/传，再让正文引用它。三种方式：

### 方式一：按提示绑定（推荐）

两个地方都能看到提示：

- **框选页**（尚未保存）：你在正文里写了 `[图1]` 却还没裁图时，卡片头部会出现红色「缺图」标签，卡片里列出 **「裁图到 [图N]」** 按钮。
- **错题库预览窗**（已保存）：图片附件区域显示

> 题干引用了 `[图1]`　`[图2]` 但还没图片：**[上传到 [图1]]** **[框选到 [图1]]**

- **上传到 [图N]**：选一张本地图片，上传后直接编号为 `[图N]`（覆盖同编号的旧图）。
- **框选到 [图N]**：进入裁图模式，在题目原图上框选图形，裁好的图绑定为 `[图N]`。

### 方式二：普通裁图 / 上传，再改绑

在预览窗「裁图」或「上传图片」，会按 `1、2、3…` 顺序自动分配编号；然后在下拉框里把某张图**改绑**到你想要的编号：

!!! tip "裁图是全局的：不分题框内外"
    预览窗进「裁图」后，只要这道题有整页原图，就**默认在整页照片上裁**（可取消勾选「从整页原图裁」回到题目图）。
    所以图注在题目旁边、图形跨到题目框外都能裁到。框选流程、编号、改绑、绑定完全一样。

```text
[图2] ▾   ← 下拉列出所有可用编号，选中即改绑
[图2] [重裁] [插入] [删除]
```

改绑会自动**同步改写正文里的引用**（`[图2]` → `[图5]`），不会出现图和文字对不上。

### 方式三：插入引用

点图卡片的 **「插入」** 按钮，会在「识别内容」光标处插入 `[图N]`。

## 图注：图片正下方的说明文字

语法：**单独一行**写 `[图注:说明文字]`，放在图片行的**下一行**，就会居中排在图片正下方（字号 88%）：

```text
[图1]
[图注:图 1　某装置示意图]
```

也可以点「插入图注」按钮把模板插到光标处。图注里的 `[图1]`、`$公式$` 等语法同样支持。

## 图片大小与对齐

在「识别内容 / 答案 / 解析」里直接写标记：

| 写法 | 效果 |
|---|---|
| `[图1]` | **默认**：高度 = 版心 24%（约 5.3cm），宽度按原图比例自动算，居中 |
| `[图1\|12%h]` | 高度 = 版心 12%（适合小题图）|
| `[图1\|6cmh]` | 固定高度 6cm |
| `[图1\|80%]` | 宽度 = 版心 80% |
| `[图1\|8cm]` | 固定宽度 8cm |
| `[图1\|50%\|left]` | 宽度 50% + 左对齐（可 `left` / `center` / `right`）|

- **整行只写图** = 单图（或一行多图自动并排）；**图与文字同行** = 行内插图（此时对齐参数不生效）。
- 不论哪种写法都**不会超出版心**：过高的图会自动改按高度定尺寸，过宽的图自动改为 `width: 100%`。
- 未裁好的图会渲染成红色提示「图N未裁好」，不影响其他内容；`[图]`（不带编号）表示整道题的原图。

### 默认高度整体调整

组卷页 →「卷头与页眉设置 → 图片默认高度」：`16% / 20% / 24% / 28% / 32%`（默认 24%，约 5.3cm）。想统一改大改小就调这里，不用逐题改标记。

## 图块管理

| 操作 | 说明 |
|---|---|
| 重裁 | 重新框选该图块，覆盖原图（用于裁歪了/多裁了）|
| 改绑 | 下拉改编号，同步改写引用 |
| 删除 | 删除图块（正文里若还引用它，渲染时显示红色缺失提示）|
| 上传 | 本地图片直接作为图块（`gif/bmp` 也支持）|

## 重新识别（重跑 AI）

点题目的 **「AI 识别」**：

- 会先保存当前编辑，避免识别结果与未保存内容冲突；
- **会替换「识别内容」**（有内容时弹确认）；
- 已裁/已上传的**图块保留**，但 `[图N]` 标记位置可能变化——重识别后请核对一下引用编号是否需要改绑。

## 手动添加的纯文字题

手动添加的题可以没有图片，此时没有「AI 识别」「裁图」入口；但 `[图1]`、`[图注:…]`、`$公式$` 等语法照常可用（可用「上传图片」补图）。
