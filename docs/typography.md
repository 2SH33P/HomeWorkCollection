# 排版微调速查

所有调整都**不用改代码**，改完重新生成 PDF 即可。

## 正文标记（写题干/答案/解析里）

| 标记 | 作用 |
|---|---|
| `**文字**` | 黑体（原题的加粗/黑体）|
| `*文字*` | 楷体（原题的楷体/斜体）|
| `***文字***` | 楷体加粗 |
| `==文字==` | 宋体加粗（描边合成）|
| `++文字++` | 黑体加粗 |
| `^文字^` | 上标角标，如 `乡校^①^`、`清机^[注]^` |
| `$...$` | 数学/化学公式（LaTeX，经 mitex 渲染）|
| `**材料一：**`（单独一行）| 材料标签，齐左 |
| `::: poem` … `:::` | 整首诗歌/词曲：整段居中 + 加大行距，每句一行 |
| `::: quote` … `:::` | 注释、出处、摘编说明、引文：左右缩进 |
| `::: center` … `:::` | 逐行居中 |
| `\| 表头 \| 表头 \|` + `\| --- \| :--: \|` | 表格（Markdown 管道表 → 三线表）|

!!! note "表格对齐"
    第二行分隔行决定各列对齐：`--:` 右对齐、`:--:` 居中、`---` 居中。

## 图片标记

| 写法 | 效果 |
|---|---|
| `[图1]` | 默认：高度 = 版心 24%（约 5.3cm），宽度按比例自动，**右对齐** |
| `[图1\|12%h]` / `[图1\|6cmh]` | 指定高度（版心百分比 / 厘米）|
| `[图1\|80%]` / `[图1\|8cm]` | 指定宽度 |
| `[图1\|50%\|left]` | 指定宽度 + 对齐（`left` / `center` / `right`）|
| `[图1]` + 下一行 `[图注:说明文字]` | 图片**正下方**居中的说明文字（88% 字号）|
| `[图]` | 整道题的原图（不带编号，少用）|

整行只写图 = 单图（或一行多图并排）；图与文字同行 = 行内插图。任何写法都不会超出版心。

## 卷头 / 页面参数（组卷页设置）

| 参数 | 可选值 |
|---|---|
| 正文字号 | 10.5pt（五号）/ 11pt / 12pt（小四）/ 14pt（四号）|
| 行距 | 0.95 / 1.25 / 1.5 / 1.75 倍 |
| 段落首行缩进 | 0 / 2 字符 |
| 图片默认高度 | 16% / 20% / 24% / 28% / 32% 版心高 |
| 页面 | 185×260mm，页边距上下 2cm、左右 2.2cm（固定，16 开）|

## 换字体

内置字体随仓库打包在 `fonts/`：

| 文件 | 用途 |
|---|---|
| `simsun.ttc` | 正文中文（宋体）|
| `simhei.ttf` | 大题标题 / `**粗体**`（黑体）|
| `simkai.ttf` | `*斜体*`（楷体）|
| `times*.ttf` | 西文与数字（Times New Roman 正/粗/斜）|

**换法一（最简单）**：把 `fonts/` 里的文件替换成**同名**文件（例如换成思源宋体后命名为 `simsun.ttc`），重启服务即可，排版代码不用改。

**换法二（文件名不同）**：打开 `tools/crop-tool/app.py`，改这四个变量里的字体名，然后重启服务：

```python
# 排版用的字体（Typst 用的是字体的内部名称，不一定等于文件名）
# let F_LATIN = "Times New Roman"
# let F_SONG  = (F_LATIN, "SimSun")
# let F_HEI   = (F_LATIN, "SimHei")
# let F_KAI   = (F_LATIN, "KaiTi")
```

!!! warning "字体要放在数据目录旁边"
    exe 方式运行时，`fonts/` 与 `typst-packages/` 必须和可执行文件在**同一目录**。

## 学科推荐参数

| 学科 | 建议 |
|---|---|
| 语文卷 | 小四 12pt + 1.5 倍行距 + **首行缩进 2 字符** |
| 数学 / 理综 | 五号 10.5pt + 0.95 倍行距 + 不缩进 |
| 英语卷 | 题目文字保持英文原样；完形/语法填空小题号（41. 61.）会保留；填空 `______` 与 `(be)` 原样；选项支持 A～G（七选五）|

## 分节块

手动添加题目时勾选「作为分节块」，该条**不参与编号**，只输出一行黑体标题，用于：

- 大题层级标题：`一、阅读（72 分）`、`（一）现代文阅读 I（本题共 5 小题，19 分）`
- 整段阅读材料：内容里写 `**材料一：**` 与材料正文

## 排版问题排查

| 现象 | 处理 |
|---|---|
| 显示红色「图N未裁好」 | 该编号还没有图片，去预览窗「裁图」或「上传到 [图N]」 |
| 图片太大/太小 | 用 `[图1\|60%]` 等标记，或改「图片默认高度」|
| 公式显示成源码 | 检查 `$...$` 是否成对；化学式用 `\ce{}` 也支持（内部会预处理）|
| 换的字体没生效 | 确认文件名/内部名正确、字体与程序同目录、已重启服务 |
| 中文变方框 | 字体文件损坏或不是中文字体；换回内置字体试试 |
| 英文数字不是 Times | 确认 `F_LATIN` 指向的字体存在 |
