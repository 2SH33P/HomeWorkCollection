# 整页框选与裁图

入口：顶部/底部导航 **「① 整页框选」**（URL `/editor`）。

## 1. 上传整页照片

点上传按钮选择试卷照片（`jpg / jpeg / png / webp / bmp`），可一次选多张。上传后自动生成缩略图，首页显示所有页面。

- 每页右上角可勾选，支持**批量删除**页面。
- 页面按上传时间编号（`P1`、`P2`…）。

!!! tip "拍照建议"
    尽量正对、光线均匀、避免阴影；手机原图即可（识别清晰度在设置页调）。同一张试卷可拍多页，最终统一框选。

## 2. 框选题目

顶部工具栏有三种模式：

| 模式 | 用途 |
|---|---|
| **框题** | 拖拽画出题目区域（每框 = 一道题）|
| **缩放** | 拖动平移 / 滚轮 / 双指缩放 / 「适应屏幕」按钮 |
| **编辑** | 微调已有框的位置和大小 |

操作要点：

- 在画布空白处**拖拽**即新建一个框；框的**四角、四边**都可拖动微调（触摸与鼠标分别设了容差，手指也能抓得住）。
- 点框内部可拖动整体位置；点圆点手柄缩放。
- **撤销 / 重做**：最多 60 步，快捷键 `Ctrl+Z` / `Ctrl+Shift+Z`。
- 鼠标悬停在框上会出现大图预览，方便核对框得对不对。

### 续块（一道题被拆成几块 / 跳页）

一道题被分栏截断、或跳页时，用「续块」把**另一块图像**并进这道题。两种用法都行：

| 顺序 | 操作 |
|---|---|
| 先框好再连（常用）| 正常框出两块 → 点**后面那块**卡片上的「续块」→ 它并入上一题 |
| 先连再框 | 点**第一块**的「续块」开启 → **下一个**新框选的框会自动并入（一次性；要接着并就在新块上再点一次「续块」）|

**续块只是一块图像，不是一道题：**

- 它**不参与 AI 识别**、**不携带任何文字** —— 题干 / 答案 / 解析 / 关键字 / 难度 / 大题**全部用首块的**；
- 保存时它**只把图像并进首块**：已经单独裁好的图块直接并入，否则整块图像作为图块 `[图N]` 接在首块题干后面；
  **不会**把它的文字接到首块里，也**不会**另占一个新编号。

其它细节：

- 右侧列表里续块不单独占卡片，只是首块卡片下方的一行：`续 1  P1 · 摘要  [取消续块]`。
- 续块没有自己的字段，也没有 AI 识别 / 裁图按钮；要给这道题裁图，直接用首块的「裁图」（页面上任意位置都能框）。
- 首块的「AI 识别」**只识别这道题自己**，不会再把续块也识别一遍。
- **取消续块** = 移除这一块：已裁好的图块并回首块，本块从草稿里移除；**首块的文字不会被改动**，
  也不会变成一道新题目。误操作按 `Ctrl+Z` 撤销。
- 点首块上的「结束续块」= 不再自动接下一框（已并入的块不受影响）。
- 画布编号：首块 `1`、`2`…，续块 `1-续1`、`1-续2`；画布上续块是橙色虚线框。

## 3. 裁剪题内图形（裁图）

题里的图形/示意图/表格图要单独裁出来，供排版时插图使用。

1. 在右侧「框选列表」里**展开该题卡片，点卡片上的「裁图」**
  （也可以先在画布上点选题目框，再点工具栏的「裁图」）。
2. **在页面任意位置拖拽框选图形**——没有范围限制，图形画在题框外、题框画得太紧、图形在续块里，都能直接裁。
   （画布上的红框只是提示“这段图属于哪道题”，不限制框选）。
3. 拖好后点 **「确认」**，会接着框选下一个（**可连续裁多张**）；裁完点「结束裁图」。
4. 裁好后卡片上会出现**图块缩略图 + `[图N]`**；点图 = 把 `[图N]` 插到题干光标处，点 `✕` = 删除（同时去掉正文引用）。
5. 已保存的题在错题库预览窗裁：进「裁图」后**默认从整页原图裁**（有原图时），同样是页面上任意位置都能框。

!!! tip "AI 识别后就知道该裁几个"
    AI 会按图形在题目里的位置自动插入 `[图1]`、`[图2]`… 标记。识别完成后卡片头部会出现红色的「缺图」小标签，
    卡片里也会列出 **「裁图到 [图1]」** 这类按钮——直接点它，框选后的图就会**绑定到该编号**（不会再重复添加引用）。
    已保存的题则在预览窗「图片附件」里按提示绑定，详见 [AI 识别与图片](figures.md)。

## 4. 每题可填的字段

右侧「框选列表」里每个框都可展开编辑：

| 字段 | 说明 |
|---|---|
| 大题归类 | 如「三、解答题」。点 **▾** 可从该科目的预设大题里选（预设来自组卷页的「大题模板」）|
| 关键字 | 搜索用，逗号分隔，如 `三角函数,图像` |
| 难度 | 1～5 星（自动组卷会用到）|
| 题干 + 选项 | 可先留空，保存后由 AI 自动识别填入；也可手写（`[图1]` 表示图块）|
| 答案 / 解析 | 可选，组卷时可作为文末附录 |

每题还有一个 **「AI 识别」** 按钮，可现场单独识别该题。

## 5. 保存到错题库

1. 左侧顶部选 **科目（统一）**——本次保存的所有框都用这个科目。
2. 点 **「保存到错题库」**。
3. 弹窗确认「科目」与「本次将保存 N 个框」（已入库的框会自动跳过，弹窗里会写明），确认后写入题库。
4. 保存成功后，程序在**后台**对每道题做 AI 识别（已有内容不会覆盖，保护手动输入）。
5. **保存后草稿不会消失**：框还在原位，并多一个绿色的 **「已入库 MA0012」** 标记；
   再点「保存到错题库」时已入库的框会被**自动跳过**（不会重复添加）。
   想把某块重新入库（例如改完想重存一份）：点那个绿色标记 → 它就变成「待入库」，下次保存会新增一条题目（原题保留）。

!!! warning "保存前会确认科目"
    科目选成「未分类」时弹窗会提醒。科目决定编号前缀（如 `数学` → `MA0001`），选错会写进题库，事后可在错题库里批量改科目。

## 6. 草稿：永远保留，除非你主动删

框的位置、已填内容、裁好的图块都会自动存到本机 + 服务器（`drafts.json`），刷新、关浏览器、换设备都不丢；
**加入错题库后也不会被清掉**。

主动删除草稿的三种方式：

| 操作 | 效果 |
|---|---|
| 单块「删」 | 只删这一个框 |
| 「清空全部」 | 删掉所有页的框选草稿（本机 + 服务器）|
| 删除整页照片 | 连同该页的草稿一起删 |

列表上方会实时显示：`已框 N 块（M 题）：X 块待入库 · Y 块已入库`。

## 小技巧

- 先「适应屏幕」再框，避免坐标被缩放影响（程序会自动换算，但看着舒服）。
- 一张卷先粗框所有题，再逐题点开填大题归类和难度，比框一个填一个快。
- 图形多的题（几何/实验装置）先不急着裁，等 AI 识别完标记出 `[图1][图2]` 再按编号裁，不会漏也不会错位。
