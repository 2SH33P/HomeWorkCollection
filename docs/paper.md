# 组卷与打印

入口：**「③ 组卷」**（URL `/paper`）。

## 1. 选题

- 在错题库里点题目的图片/「加入组卷」按钮加入；或在组卷页 **输入编号添加**（如 `MA0003 / CH0001`，可逗号分隔、可批量粘贴）。
- 「已选题目」列表会显示缩略图和题干摘要，可 **↑ ↓ 调整顺序**、**移除**、**就地改大题**。
- **排序规则**：同一大题内保持你的添加顺序；点「按大题排序」或改动大题后，会自动按大题数字序号（一、二、三…）重排。生成 PDF 时也会自动按大题排序。
- 同一道题的**续块**只占一个题号，后续块显示为「(续)」。

## 2. 卷头与页眉设置

| 设置 | 说明 |
|---|---|
| 卷头标题 | 默认「错题重组试卷」|
| 科目名 | 留空则自动取题目的科目；可写「数　学」这种手工加宽 |
| 副标题 | 显示在科目名下方，如「（适用省份：山东、浙江…）」|
| 注意事项 | **第一行**为黑体标题，其余每行一条 |
| 页眉文字 | 每页顶部，可留空 |
| 正文字号 | 五号 10.5pt（数学/理综）/ 11pt / 小四 12pt（语文常用）/ 四号 14pt |
| 行距 | 0.95 / 1.25 / 1.5 / 1.75 倍 |
| 段落首行缩进 | 不缩进（数学/理综）/ 缩进 2 字符（语文常用）|
| 图片默认高度 | 16% / 20% / 24%（推荐，约 5.3cm）/ 28% / 32% 版心高 |

这些设置会记忆在本机浏览器（localStorage），下次打开还在。

## 3. 文末附加

| 选项 | 说明 |
|---|---|
| 文末附加 | 不附加 / 参考答案 / 解析 / 参考答案 + 解析（自动分页排在文末）|
| 附编号对照页 | 附一页「卷面题号 ↔ 题库编号（含大题）」对照表 |

## 4. 生成

| 按钮 | 产物 | 特点 |
|---|---|---|
| **生成 PDF** | `.pdf` | **文字可复制/可搜索**；公式经 mitex 渲染；图片按 `[图N]` 插入；页脚「第 X 页　共 Y 页」；16 开高考卷风格（185×260mm，上下 2cm / 左右 2.2cm 页边距）|

!!! tip
    排版整齐、文字可复制、体积小、能自动分页与编号。

## 试卷排版默认风格

- 正文：中文**宋体**、西文/数字 **Times New Roman**、五号、1.5 倍行距（可在设置里改）。
- 大题标题：**黑体**小四（来自题目的「大题归类」；空/未命名则不出标题行）。
- 题目之间 0.45cm 间距；选项按内容宽度自适应 **一行四列 / 两列 / 一列**。
- `*楷体*` → 楷体、`**黑体**` → 黑体、`==宋体加粗==`、`++黑体加粗++`、`^上标^`。
- 详细标记与调法见 [排版微调速查](typography.md)。

## 打印建议

- PDF 生成后浏览器会新开标签；用 `Ctrl+P` 打印时选 **实际大小 / 100%**（不要「适应页面」，否则页边距会被缩）。
- 网页打印版把浏览器页边距设为「默认」或「无」，纸张 A4。

## 组卷页的其它工具

- **大题模板**：按科目预设大题，供框选/预览时一键选择（见 [错题库与编号](library.md)）。
- **自动组卷**：按大题 + 星级自动抽题、一次出多份 → 见 [自动组卷](auto-paper.md)。
