# 配置 AI 识别

AI 只做一件事：把**裁剪后的单题图片**转成文字 + LaTeX 公式。程序不绑定任何厂商，任何 **OpenAI 兼容**的接口都能用。

## 快速配置（智谱清言 · 免费）

在 **设置 → AI 识别服务 → 修改配置** 里填：

| 字段 | 填什么 |
|---|---|
| API 地址（OpenAI 兼容） | `https://open.bigmodel.cn/api/paas/v4` |
| 模型名 | `glm-4v-flash` |
| API Key | 你的智谱 key |
| 识别清晰度 | `推荐 1600px`（免费模型建议 1200～1600）|
| 额外一轮 AI 校对 | **关闭**（请求数翻倍，最容易撞限流）|

保存后点 **测试连接**（走文本接口，能通说明地址/key 正确）；真正的识图要在拿到题后点「AI 识别」验证。

!!! tip "glm-4v-flash 是视觉模型"
    它支持图片输入且免费。注意不要用纯文本模型（如 `deepseek-chat`）——会静默忽略图片，输出残缺内容。

## DeepSeek 预设

预设下拉里选 **DeepSeek 多模态（deepseek-flash）**，会自动填好地址和模型，再填 key 即可。

## 其他任意 OpenAI 兼容接口

只要同时满足：

1. `POST {base_url}/chat/completions`
2. 支持 `messages[].content[].type = "image_url"`（data URI base64）
3. `Authorization: Bearer <key>`

填 `base_url` + `model` + `key` 即可。`base_url` 一般到 `/v1` 或 `/paas/v4` 为止，程序会自动拼 `/chat/completions`。

## 三种配置方式

=== "设置页（推荐）"

    设置 → AI 识别服务 → 修改配置 → 保存。配置写入 `.ai_config.json`。

=== "配置文件"

    在**数据目录**（exe 版即 exe 所在目录）创建 `.ai_config.json`：

    ```json
    {
      "base_url": "https://open.bigmodel.cn/api/paas/v4",
      "model": "glm-4v-flash",
      "key": "你的 API Key"
    }
    ```

=== "环境变量（不写盘，优先级最高）"

    ```bash
    export AI_BASE_URL="https://open.bigmodel.cn/api/paas/v4"
    export AI_MODEL="glm-4v-flash"
    export AI_API_KEY="你的 API Key"
    ```

    环境变量会**覆盖**配置文件里的同名项，适合不想把 key 落盘的场景。

## 各选项说明

| 选项 | 说明 |
|---|---|
| 识别清晰度 | 图片最长边像素：`1200`（快）/ `1600`（推荐）/ `2200`（小字更准）/ `2800`（最准最慢）。越大越慢、越费额度 |
| 识别原题字体差异 | 开启后 AI 会标注原题的加粗/楷体，PDF 会用黑体/楷体对应排版 |
| 额外一轮 AI 校对 | 对照原图再核查一遍（错别字/公式/括号/选项），**耗时和请求数约翻倍** |
| 测试连接 | 只测地址与 key 是否可用（纯文本请求），不验证模型是否支持图片 |

## 运行日志

设置页底部「运行日志」记录最近 300 条 AI 调用：时间、类型（识别/校对/重新识别/自动组卷…）、模型、耗时、结果。识别失败时来这里看原因。

## 限流与失败排错

!!! warning "免费模型的常见问题"
    免费视觉模型通常有 QPS / 并发限制。本工具在保存一批框选题后会用 **3 个并发**后台识别，一次框很多题时容易返回 `429` 或超时，表现为个别题「识别内容为空」。

处理办法：

- 一次少框几题（比如 5～8 道），等识别完再继续。
- **关闭**「额外一轮 AI 校对」（请求数翻倍）。
- 识别清晰度调到 1200/1600。
- 某题内容为空时，在错题库/预览窗点该题的 **「AI 识别」** 单独重试（重试会覆盖识别内容，会先弹确认）。
- 换一个 API 服务商，或稍后再试。

## 安全须知

- Key 以**明文**保存在 `.ai_config.json`：该文件已在 `.gitignore` 中（不会推到 GitHub），导出 ZIP 也**不包含**它；界面上只显示掩码（如 `abcd****wxyz`）。
- AI 配置是**全局**的：切换数据仓库不会改变它。
- 图片会发送到**你自己配置**的服务商；敏感题目请谨慎。
- 服务本身无鉴权，详见 [常见问题 FAQ](faq.md) 的安全部分。
