# 自动组卷

位置：组卷页 → 折叠面板 **「自动组卷」**。
按「大题 + 星级」约束从题库抽题，**一次可出多份互不重复的卷子**。

## 操作步骤

1. 选 **科目**、填 **份数**（1～50）。
2. 给每个大题填 **题量**（如选择题 8 道、解答题 6 道）。
   - 点 **「按题库一键填充」**：按份数把题库题量均分到各大题（每个大题上限 8 道），再手动微调。
3. （可选）点 **「高级约束 ▾」** 给每个大题设各星级的**最少 / 最多**：
   例如「2 星 2～3 道、3 星至少 2 道、4 星最多 2 道」，留空 = 不限。
4. （可选）**指定题目**：输入编号（如 `MA0003`）或点「加入当前勾选」把错题库里勾选的题设为指定题。
5. （可选）勾选 **关键字不重复** / **避开上次用过的题**；选 **难度倾向**（不限 / 偏易 / 中等 / 偏难）。
6. 点 **「预检」** 看最多能出几份、卡在哪；通过后点 **「生成」**。

## 指定题目（每份必含）

「指定题目」列表里的题：

- **每份卷子都会包含**（不是随机抽中）；
- 排在该大题的**最前面**（按你添加的顺序）；
- **不占随机配额**：该大题的随机题量 = 题量 − 指定题数；
- 不参与「跨份不重复」的判定（它本来就每份都有）。

!!! tip "典型用法"
    「必考的压轴题 + 其余随机」「老师划的重点题每份都出」「上次考试的原题必须重现」。

## 输出

生成后每份卷子显示分组题目列表（编号 + 星级）：

| 按钮 | 作用 |
|---|---|
| 载入到组卷 | 把这份卷子放进「已选题目」，可在下方微调后生成 PDF |
| 导出 PDF | 直接按当前卷头设置导出这一份的 PDF |
| 全部导出 ZIP | 把已生成的所有份导出为一个 ZIP（每份一个 PDF，文件名 `paper-01.pdf`…）|

## 算法（了解即可）

1. 先按各题量算出**每份卷每个星级各拿几道**（保证星级上下限与题量都能满足），配额按剩余份数均分，避免某一份把稀缺星级的题用光。
2. 每个大题、每个星级**洗牌后发牌**，份与份之间题目完全不重复。
3. 卷内排序：大题顺序 = 你填写的顺序；大题内**星级从低到高**，指定题目排最前。

## 预检信息怎么看

- `最多可出 N 份`：受题量、星级上下限、关键字去重、指定题数共同限制。
- 提示会指出卡在哪个大题/星级，例如「3 星题目不足」→ 加题或放宽星级约束。
- 生成失败时不会改动题库，只会提示原因。

## 配置记忆

题量、星级约束、份数、难度倾向、指定题目、勾选项都会按**科目**记忆在本机浏览器，下次打开自动恢复。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示「最多只能出 1 份」 | 题量相对题库太多，或某星级上下限太紧 |
| 提示「关键字去重要求下不足」 | 关闭「关键字不重复」，或减少题量/补题 |
| 指定题没出现在某份里 | 指定题的科目/大题与当前科目不匹配；请检查它的大题归类是否在该科目的大题列表里 |
| 想重抽一批 | 勾选「避开上次用过的题」后再次生成，或改变份数 |
